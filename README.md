# Welfare Express

> [English](/README.en.md) | 简体中文

一个专门用来写推广文章的仓库，主要收集各种羊毛、福利和优惠信息，方便整理成合集。

## 目录结构

```
Welfare-Express/
├── articles/              # 文章目录（每篇一对文件）
│   ├── _template.zh.md    # 中文文章模板
│   └── _template.en.md    # 英文文章模板
├── assets/                # 图片等资源
└── README.md              # 本文件（中文）
```

## 写作约定

- 每篇文章一对文件，放在 `articles/` 下：
  - 中文版：`文件名.zh.md`
  - 英文版：`文件名.en.md`
- 文件名用日期 + 简短标题，例如 `2026-08-15-新用户福利合集.zh.md`
- 每个版本顶部放语言切换链接（见模板），方便读者切换
- 所有 AFF 链接统一放在文末的「推广链接」小节，方便追踪和管理
