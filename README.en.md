# Welfare Express

> [English](/README.en.md) | 简体中文

A repo dedicated to writing promotional articles, collecting deals, freebies, and coupons into handy roundups.

## Directory Structure

```
Welfare-Express/
├── articles/              # Articles (one pair of files each)
│   ├── _template.zh.md    # Chinese article template
│   └── _template.en.md    # English article template
├── assets/                # Images and other assets
└── README.en.md           # This file (English)
```

## Writing Conventions

- Each article is a pair of files under `articles/`:
  - Chinese version: `name.zh.md`
  - English version: `name.en.md`
- Name files with date + short title, e.g. `2026-08-15-new-user-deals.zh.md`
- Put a language switch link at the top of each version (see templates)
- Keep all AFF links in the "Affiliate Links" section at the end for easy tracking
- Note the last-updated date at the top so readers know if it's still valid
